# 聊天及文件的安全邊界

Web 只提供讀取文件及回答問題，沒有 PostgreSQL 寫入、任務或會面 API。保留的歷史 MCP／資料庫工具不在 Web 程序的 import 或啟動路徑。

- 訊息最多 4,000 字元，歷史只接受 user／assistant；傳給模型的歷史最多十則及合計 12,000 字元。
- 純提示注入在圖執行前中止。混合正當 HR 問題與惡意指令時仍可回答政策，但系統明確將問題、歷史和文件當作不可信參考資料。
- 輸出檢查保留已知劫持回覆及系統提示片段偵測；來源只可來自實際檢索到的白名單文件。
- 文件 API 共用檔名白名單，檢查 resolve 後路徑；Markdown 不啟用原始 HTML 執行。
- GPT 認證、額度及連線故障可以切換 xAI；內容安全拒絕不會以備援繞過。
- 供應商 Key 留在後端，xAI 不繼承 GPT 代理的自訂授權標頭。使用 `store=False`；不把 Key 或完整對話記錄到用量日誌。
- CORS 以 `CORS_ORIGINS` 明確列出前端來源。此 Demo 沒有登入或應用層限流，公開展示的 API 額度仍需由平台／代理設定控制。

這些措施不代表模型可完全抵抗提示注入。回歸測試及可選 Golden 安全題目見 [EVALS](EVALS.md)。
