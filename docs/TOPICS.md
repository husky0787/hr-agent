# 文件主題及搜尋方式

目前四份文件有 40 個二級章節。`shared/topics.py` 每次從實際文件標題讀取主題，使用繁體／簡體中文及英文同義詞辨識問題；這一步是本地規則，不會額外呼叫 GPT。

| 文件名稱 | 實際章節／主題 |
| --- | --- |
| 僱員手冊（13 項） | 公司及團隊；公司有薪年假；未放取年假及結轉；病假及醫生證明書；事假及其他假期；出糧日期及糧單；更改出糧戶口；工作時間、午膳及遲到；加班及補假；公司假期日曆；試用期及轉正；離職及工作交接；行為守則 |
| 福利及開支報銷指南（10 項） | 醫療保險登記；醫療保障及索償；強積金登記及供款紀錄；報稅文件；產假；侍產假；健康津貼；開支報銷貨幣及收據；差旅、交通及餐飲開支；報銷審批及付款 |
| IT 設定及資訊保安指南（10 項） | 工作電腦；VPN 設定；Slack 設定；磁碟加密；雙重認證；密碼管理；個人資料及機密文件；可疑電郵、裝置遺失及保安事故；開發環境及系統權限；IT 支援聯絡方式 |
| 首 30 天入職安排（7 項） | 第一星期：完成基本入職安排；第二星期：熟習團隊及工作流程；第三星期：參與實際工作；第四星期：檢視首月進度；工程團隊專屬安排；入職文件提交方式；入職期間遇到問題 |

例如「請介紹公司的有薪年假、醫療保險登記期限及健康津貼。」會辨識為：

| 搜尋主題 | 對應文件 | 應找出的內容 |
| --- | --- | --- |
| 公司有薪年假 | 僱員手冊 | 每年 25 天、申請安排 |
| 醫療保險登記 | 福利及開支報銷指南 | 入職 30 天內登記 |
| 健康津貼 | 福利及開支報銷指南 | 每年 HKD 2,000、申請安排 |

兩個或以上主題會產生各自的集中搜尋文字，例如「公司有薪年假的政策內容及適用安排」。尚未快取的文字會放在同一個 Jina embedding 請求，然後以文件及章節 metadata 限定搜尋範圍。每個主題最多取兩個區塊，先各取一個，再補第二個，總數最多六個；超過六個主題會請使用者分開提問。中文和英文問法對應相同主題時可重用查詢向量。

只有一個已知主題，或沒有辨識出主題時，保留原問題的向量 top-3 搜尋；短追問可帶入最近一輪對話。規則無法理解所有同義說法、否定或隱含主題，未命中的用語仍可透過原有語意搜尋尋找；這不是另一個 LLM 自動推理步驟。

完整同義詞見 `shared/topics.py` 的 `ALIASES`。比對會優先採用較長詞組，避免「侍產假」同時誤判為「產假」，並檢查英文縮寫的單字邊界。新增章節後，完整標題會自動成為可辨識用語；常用別稱須補進 `ALIASES`。新增文件仍需先加入 `shared/documents.py` 白名單及中文標題。

答案引用顯示中文文件名稱，例如 `[僱員手冊]`；內部仍使用原有檔名讀取原文，因此不需要重新命名文件。未找到某項資料只代表本次搜尋片段不足，不能據此斷言整份文件沒有記載。
